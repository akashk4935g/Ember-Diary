# 🔥 Ember Diary

A beautiful, offline-first personal productivity dashboard combining a **daily diary, habit tracker, planner, focus timer, alarms, and profile system** in a single lightweight web app.

## ✨ Features

* 📔 **Daily Diary**

  * Write daily journal entries
  * Record your mood
  * View previous entries
  * Writing streak tracking

* 🎯 **Habit & Activity Tracking**

  * Create custom trackers
  * Habit, diet, and sleep categories
  * Daily completion tracking
  * Streak calculation

* 📅 **Daily Planner**

  * Add tasks for specific dates
  * Mark tasks as completed
  * Track daily completion percentage
  * Navigate across days

* ⏱️ **Focus Mode**

  * 5, 15, 25 and 45-minute focus sessions
  * Start, pause, resume and reset
  * Visual countdown ring

* ⏰ **Reminders**

  * Create custom alarms
  * Bedtime reminder
  * Browser notifications
  * Audio notification

* 🌙 **Themes**

  * Dark mode
  * Light mode
  * Responsive mobile-first interface

* 💾 **Backup & Restore**

  * Export personal data as JSON
  * Import backup files on another device
  * Data stored locally in the browser

## 🛠️ Built With

* HTML5
* CSS3
* Vanilla JavaScript
* Browser LocalStorage
* Web Notifications API
* Web Audio API

## 🚀 Run Locally

No build system or dependencies are required.

Simply open:

```text
index.html
```

in a modern web browser.

## 🌐 Deploy with GitHub Pages

1. Push the project to GitHub.
2. Open **Settings → Pages**.
3. Select the repository branch.
4. Select the `/ (root)` folder.
5. Save.

Your Ember Diary app can then be accessed through GitHub Pages.

## 💾 Data & Privacy

Ember stores application data locally in the browser using `localStorage`.

Your diary entries, trackers, tasks, profile information, and other application state are not sent to a backend server.

The app also provides JSON export/import functionality for backups.
